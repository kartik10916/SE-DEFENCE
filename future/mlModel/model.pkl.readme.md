# model.pkl

This file is generated by running the training script:

```bash
cd future/mlModel
pip install scikit-learn pandas numpy
python train.py
```

The script will output `model.pkl` in this directory.
After training, the model can be loaded with:

```python
import pickle
with open('model.pkl', 'rb') as f:
    model = pickle.load(f)

prediction = model.predict(["Urgent: click here to verify your account"])
probability = model.predict_proba(["..."])[0, 1]
```
